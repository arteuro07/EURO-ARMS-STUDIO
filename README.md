# EURO-ARMS-STUDIO

Studio de production de mini-documentaires historiques en français.

## Direction artistique
- Documentaire cinématique, matières réalistes et composition sobre.
- Three.js pour les scènes 3D, la profondeur, les lumières et les mouvements de caméra.
- Étalonnage réglable : exposition, contraste et saturation.
- Palette maîtrisée : ardoise froide, métal neutre, accents bronze chauds.
- Éviter les blancs brûlés, les noirs bouchés, la saturation excessive et les reflets irréalistes.
- Les objets historiques doivent être documentés et distingués des représentations fictives du jeu.

## Démarrer
```bash
npm install
npm run dev
```

## Construire
```bash
npm run build
```

Le prototype actuel valide le moteur visuel Three.js et les réglages d'étalonnage. Les modules recherche, script, voix, génération d'illustrations, animation par plans et export vidéo seront ajoutés séparément, avec tests à chaque étape.

## Règle de production
Ne jamais présenter une scène statique avec un simple zoom comme une animation complète. Chaque plan final doit avoir un mouvement réel : objet, personnage, caméra, lumière ou éléments d'environnement.
